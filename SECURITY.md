# Sicherheit / Security

## Deutsch

Hast du eine Sicherheitslücke in **WetterCube Biker** gefunden? Bitte melde sie **vertraulich** und nicht als öffentliches Issue, per E-Mail an **info@wettercube.de** (Betreff „Sicherheit WetterCube Biker“). Es handelt sich um ein Hobby-Open-Source-Projekt ohne feste Reaktionszeiten und ohne Prämien.

## English

Did you find a security vulnerability in **WetterCube Biker**? Please report it **confidentially** and not as a public issue, by email to **info@wettercube.de** (subject "Security WetterCube Biker"). This is a hobby open-source project without fixed response times and without bounties.
